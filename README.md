# Akachukwujohn_-mechatronic-quiz-app
Project Description 
The mechatronics quiz app is a Python application designed to test students' knownledge of mechatronics through multiple choice questions 

The application checks answers, calculates scores, displays percentage and grades, and shows the correct answers for the questions answered correctly. 

Features 
* 10 multiple choice questions.
* Automatic answer checking
* Score calculation
* Percentage and grade display
* Input validation.

How to run the Program
1. Download the mechatronic_quiz.py file
2. Open it using Python 3.
3. Run the program
4. Answer the questions by entering the correct option number
5. View ur final score and answers
